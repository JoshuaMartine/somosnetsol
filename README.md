# 🚀 NetSol - Agencia de Desarrollo de Software

Bienvenido al repositorio oficial de la landing page de **NetSol**. Somos una agencia enfocada en transformar ideas en código, especializándonos en el desarrollo de páginas web, aplicaciones móviles (iOS & Android) y sistemas a medida escalables y seguros.

## 📖 Descripción del Proyecto

Esta es una landing page moderna, minimalista y tipo "Dark Theme", diseñada para presentar nuestros servicios, portafolio de proyectos y ofrecer un canal de contacto directo con los clientes. 

El sitio está optimizado para ofrecer una excelente experiencia de usuario (UX) mediante animaciones fluidas y un diseño 100% responsivo que se adapta perfectamente tanto a pantallas de escritorio como a dispositivos móviles.

## ✨ Características Principales

- **Diseño Responsivo:** Interfaz adaptable a cualquier tamaño de pantalla (Mobile First approach).
- **Animaciones al hacer Scroll:** Implementación de la librería AOS para entradas visuales dinámicas.
- **Efectos CSS Personalizados:** Tarjetas flotantes y brillos de fondo (Glow effects) mediante animaciones keyframes.
- **Formulario Funcional:** Integración con FormSubmit para recibir correos directamente sin necesidad de backend.
- **Navegación Intuitiva:** Menú de navegación fijo con efecto cristal (backdrop-blur) y menú de hamburguesa interactivo para móviles.

## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido utilizando tecnologías web modernas sin necesidad de configuraciones complejas de empaquetadores:

- **[HTML5](https://developer.mozilla.org/es/docs/Web/HTML):** Estructura semántica.
- **[Tailwind CSS](https://tailwindcss.com/) (vía CDN):** Framework de utilidades para un maquetado rápido y moderno.
- **[JavaScript (Vanilla)](https://developer.mozilla.org/es/docs/Web/JavaScript):** Lógica del menú móvil y configuración de animaciones.
- **[AOS Library](https://michalsnik.github.io/aos/):** Librería para animaciones "Animate On Scroll".
- **[Font Awesome 6](https://fontawesome.com/):** Iconografía vectorial.
- **[Google Fonts](https://fonts.google.com/):** Tipografía principal (*Montserrat*).
